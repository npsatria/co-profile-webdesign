UX Testing UI Prototyping

Dalam proyek ini, saya mendapatkan kesempatan berharga untuk belajar membuat prototyping menggunakan Figma, dimulai dari pembuatan user flow sederhana hingga pengembangan animasi yang menarik. Proses ini memberikan saya pemahaman yang lebih mendalam tentang bagaimana merancang pengalaman pengguna yang intuitif dan efektif.

Selama proyek ini, saya juga dibina untuk meningkatkan kualitas user testing yang saya lakukan. Melalui serangkaian pengujian dengan pengguna, saya dapat mengumpulkan umpan balik yang konstruktif dan menerapkannya untuk menyempurnakan desain saya.
